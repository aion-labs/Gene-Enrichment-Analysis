# iGEA paper (CSBJ revision, 2026): analyses, figures and supplement

> **This folder is not part of the iGEA software.** It archives the analyses, figure scripts and supplement builders
> written for the manuscript *Iterative Gene Enrichment Analysis (iGEA)* (Computational and Structural Biotechnology
> Journal, manuscript CSBJ-D-26-01018, revision of November 2026). Nothing in `code/`, the app or the CLI imports
> from here. The scripts call the iGEA code in `code/` read-only.

Most analyses were written to answer reviewers' comments and were run on 14–22 November 2026. The order and every
decision are logged in [`analyses/RESULTS.md`](analyses/RESULTS.md), the lab notebook kept during the revision.
Reviewer comment IDs (R1–R5; M major, m minor) are given below where the log records them; the response letter has the full mapping.

## Rebuild everything in one command

```bash
uv venv -p 3.12 venv && VIRTUAL_ENV=venv uv pip install -r publication/csbj_2026/requirements-publication.txt
PYTHON=venv/bin/python bash publication/csbj_2026/build/make_all.sh        # output: publication/csbj_2026/rebuilt/ (git-ignored)
```

`make_all.sh` rebuilds every supplementary table and note, the Figure 1 DOT files, Figures 2–4 and Supplementary
Figures 1–6 from the archived analysis outputs in `analyses/`, renders the PDFs when Playwright is available, and
compares the rebuilt text with the submitted files in `supplement/`.

**Verified on 22 November 2026:** all 29 supplementary text/HTML files rebuilt identical in content to the submitted versions.
Figure 2 rebuilt pixel-identical. Figures 3–4 and Supplementary Figures 1–6 rebuilt with the same networks, numbers and labels;
force-directed layouts shift slightly between library versions (the submitted figures were drawn with Python 3.13,
networkx 3.7, matplotlib 3.11; the check used Python 3.12, networkx 3.5).

Not rebuilt by code: **Figure 1** was drawn by the author from `Fig1A_*.dot` and `Fig1B_*.dot`; **Supplementary Table 13** is the
DAVID functional clustering report of the first submission (DAVID web server). The text version of Supplementary Table 1,
the figure legends and the supplement index are written by hand (`supplement/`).

## Rerunning the analyses

Analyses were run with branch `csbj-revision` from commit `46af50e` (one-sided Fisher's exact test = upper tail of the
hypergeometric distribution; per-run random gene lists; two-level statistics) up to `5fb455e`. Tag the commit that accompanies
the publication (for example `csbj-2026`). Gene-set collections MSigDB v2025.1.Hs; background `data/backgrounds/all_genes.txt`.

1. Main runs: `step09_end_to_end` (CLI, `--iterative`, 10 collections, 10,000 random lists, q < 0.10) for the five inputs and the random control.
2. Communities and hubs: `step07_modules/run_modules.py`.
3. Robustness: `step03_redundancy`, `step06_stability`, `step10_extras` (random lists are cached in `~/igea_cache`).
4. Three screens: `step11_three_screens/s11a` → `s11e`, then `run_llm_screens.sh`.
5. LLM: `export OPENAI_API_KEY=...` (never stored in the scripts), then `step09_end_to_end/run_llm_all.sh gpt-6.2-sol`, `run_llm_ora.sh`, `analyze_llm_v5.py`. Model gpt-6.2-sol, 20 November 2026.
6. Figures and supplement: `build/make_all.sh`.

Most scripts take input and output folders as arguments (usage line in each docstring). Scripts that originally used absolute
paths find the repository root by looking for `pyproject.toml` (header marked `# [publication] repository-relative paths`).
Random gene lists are seeded (default seed of `per_run_null`; subsamples seed 2026), so the numbers are reproducible with the same code and collections.

## Corrections made while archiving (22 November 2026)

- Builders now write the final numbering directly. On 21 November the supplement was renumbered by order of citation and the
  files were edited after building; the builders still carried the old numbers. Old builders are in `superseded/` folders.
- Supplementary Table 6 (text) and Supplementary Note 1 had no builder; both now have one.
- Figure 1B DOT: iGEA terms are now coloured as shared with ORA at FDR < 0.05 (the first version compared with FDR < 0.10;
  the author had corrected the figure by hand). Old file in `figures/figure_1_and_dot_sources/superseded/`.
- Footers of Supplementary Tables 2 and 14 pointed to private folder names; they now name the repository paths.
- PDFs of Supplementary Tables 14B, 14C, 15 and 16 re-rendered so that their footers carry the table number, like Tables 9–12.

## Superseded material (kept for the record)

- `step01/`: reproduction of the first submission with the stored permutation null in `permutations/` (the old method).
- `fastnull/`: prototype of the vectorised engine; its README describes the two-sided test used before 20 November.
- `step02_per_run_null/`, `step05_two_layer/`: first runs of per-run random lists and two-level statistics (14–15 November,
  two-sided test). The final numbers come from `step09_end_to_end` and later steps.
- Early sections of `RESULTS.md` record numbers that later steps replaced (one universe, 16 November; one-sided test, 20 November).
- LLM answers of `gpt-6-astra` (`*/llm/`) were replaced by `gpt-6.2-sol` (`*/llm_gpt-6.2-sol/`); see RESULTS.md, Step 23.

Manuscript-editing scripts (tracked changes in Word, text drafts) are kept with the paper, not here, because they contain
unpublished manuscript text.
