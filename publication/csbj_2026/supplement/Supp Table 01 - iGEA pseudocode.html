Iterative Gene Enrichment Analysis (iGEA): algorithm

iGEA repeatedly identifies the most significant enriched term, removes its overlapping genes from the input list and repeats the enrichment analysis on the remaining genes. This is done separately for each gene-set collection, until termination criteria are met (Part 1). Random gene lists processed by the same procedure then give each selected term an empirical q-value (term level). Terms with q below the threshold form the cross-collection network, whose largest connected cluster is compared with those of the random lists (network level) (Part 2).

Part 1 · Iterative selection

FOR keyword← assignment / set operation0.01 number// note comment
1

Iterative selection, separately for each collection

Every gene set is restricted to the background before the size filter, so the input list, the gene sets and the random lists come from one gene universe. Worked example of the test: N = 350, M = 4,500, |T| = 50 and k = 15 give the table [[15, 35], [335, 4,115]].

Prepare the collectionG ← G ∩ B                                   // input genes outside the background are removed (one gene universe)results ← []FOR Collection in C:    terms ← {T ∩ B : T in Collection}           // every gene set restricted to the background    terms ← {T in terms : min_gene_set_size <= |T| <= max_gene_set_size}    U ← union of all genes in terms              // collection-specific universe    M ← |U|                                      // collection-specific background size    remaining_genes ← G ∩ U                      // each collection starts from the full input    iteration ← 1Select the most significant term    WHILE (|remaining_genes| > 0 and iteration <= max_iterations):        N ← |remaining_genes|        FOR T in terms:            k ← |T ∩ remaining_genes|              // overlap            IF k < min_overlap: skip T            table ← [[k, |T| - k], [N - k, M - |T| - N + k]]            p(T) ← Fisher's exact test, one-sided (over-representation), on table                   // = hypergeom.sf(k - 1, M, |T|, N) = P(overlap >= k); under-represented sets get large p        IF no term was tested: BREAK        top_term ← term with the lowest p(T)    // ties: order of the gene sets in the collection file        top_pvalue ← p(top_term)        IF top_pvalue >= p_threshold: BREAKRecord the term and remove its genes        top_overlap_genes ← top_term ∩ remaining_genes        record ← {            Collection: Collection.name,            Iteration: iteration,            Term: top_term.name,            "iteration p-value": top_pvalue,            "iteration overlapping genes": |top_overlap_genes|,            "Genes removed for next iteration": top_overlap_genes        }        results.APPEND(record)        remaining_genes ← remaining_genes - top_overlap_genes   // each gene: at most one term per collection        iteration ← iteration + 1    END WHILEEND FOROUTPUT: results (selected terms of all collections)

Part 2 · Two-level empirical significance testing

2a

Random gene lists, analysed exactly like the input

Two kinds of random lists are drawn, both independently from the background and both analysed exactly like the input. Lists of the input size are the reference for the network test and for the first q-value round. Reduced-size lists are needed because a q-value compares the input with chance, and chance selections come only from the input genes that are noise. Genes already explained by real terms cannot produce chance terms, so once terms are accepted the reference must be random lists the size of the unexplained part of the input (step 2b).

Random lists of the input size (network test and first q-value round)n ← |G|                                             // HIV: 265FOR i in 1..n_lists:                                // default 10,000    R_i ← n genes drawn from B without replacement      // generator seeded with (seed, n, i)    random_results_i ← Part 1 applied to R_i            // all collections, all iterations, same parametersReduced-size random lists (later q-value rounds only)reduced_sizes ← n - s, n - 2s, ..., not below n/4      // s = n/20, rounded up                                                    // HIV: 251, 237, ..., 97, ..., 69 (14 sizes)FOR size in reduced_sizes:    FOR j in 1..max(200, n_lists/10):                   // 10,000 lists: 1,000 per size        R ← size genes drawn from B without replacement  // seeded with (seed, size, j)                                                          // a fresh draw, not a subset of the lists above        Part 1 applied to R                               // all collections, all iterations, same parameters// All random lists are drawn and analysed here, once, before any q-value is computed.
2b

Term level: empirical q-value within each collection

HIV example. Round 1 compares the HIV terms with the 265-gene lists, which select about 16.0 terms per list by chance across the ten collections. The rounds settle when the accepted terms explain 168 genes; the other 97 genes are matched by the 97-gene lists, which select about 7.2 terms by chance. For Reactome HIV transcription elongation (p = 0.0085; 9 HIV Reactome terms have p ≤ 0.0085), the 265-gene lists give 2.07 chance Reactome terms per list with p ≤ 0.0085, so q = 2.07/9 = 0.23 and the term would be removed; the 97-gene lists give 0.87, so q = 0.87/9 = 0.097 and the term is kept.

FUNCTION q_values(selected_terms, list_size):
    // The rounds below are not iterations of Part 1: they start after the terms of
    // all collections have been selected, and they change only the q-values.
    signal_genes ← {}                                     // round 1: every gene is treated as noise
    REPEAT (at most 10 rounds):
        noise_size ← list_size - |signal_genes|            // genes not explained by accepted terms
        ref_size ← smallest of n and reduced_sizes that is >= noise_size
                   // rounded UP: can only over-estimate chance terms
        FOR each collection c, FOR each term t selected in c with p-value p:
            expected ← mean number of terms with p-value <= p selected in c from the random lists of ref_size
                       // when a random list of size n is scored, that list itself is left out
            observed ← number of terms with p-value <= p selected in c from the scored list
            q_raw(t) ← min(1, expected / observed)
        q ← q_raw made monotone in p within each collection   // as Benjamini-Hochberg
        new_signal ← all genes assigned to terms with q < accept_level, pooled across collections
                     // accept_level = q_threshold (0.10 when q_threshold = 1)
        IF new_signal = signal_genes: STOP                 // the accepted terms no longer change
        signal_genes ← new_signal
    RETURN q

q ← q_values(results, n)                               // the input list
kept ← terms in results with q < q_threshold          // q_threshold = 1: all terms kept
// Every random list of size n is scored by the same function in step 2d.
2c

Network from the kept terms

network ← gene-term graph: an edge between each gene and the term it was assigned to (no edge weights)
cluster ← largest connected component of network
metrics ← cluster size (genes + terms), genes, terms, edges, edges per gene
          // number of collections in the cluster: descriptive
2d

Network level: the same filter and network for every random list

The metrics describe the same cluster and are not independent tests. With 10,000 random lists the smallest attainable p-value is 0.0001.

FOR i in 1..n_lists:
    q_i ← q_values(random_results_i, n)
    kept_i ← terms with q_i < q_threshold                // q_threshold = 1: all terms kept
    metrics_i ← metrics of the largest connected component built from kept_i
FOR each metric:
    r ← number of random lists with metrics_i >= metrics
    empirical p ← (r + 1) / (n_lists + 1)
    z-score ← (metrics - mean(metrics_i)) / SD(metrics_i)      // descriptive only

communities ← Leiden (modularity) on the term-term projection of network

              // networks with fewer than 6 terms: connected components
