Supplementary Table 8. Sensitivity of iGEA results to the analysis settings

Each row changes one setting from the default (Fisher's exact test, one-sided; p < 0.01 for selection; minimum overlap of
3 genes; gene sets of 10-600 genes after restriction to the background; at most 30 iterations per collection; ten
collections). For every setting, the random gene lists were generated and analysed with the same changed setting
(2,000 random lists of the input size and 200 per reduced size for the q-value adjustment), so the term-level q-values
and the network test always match the analysis. Empirical p = (r + 1)/(n + 1); with 2,000 lists the smallest attainable
value is 0.0005 (shown as < 0.001). Jaccard: overlap with the default analysis of the same gene list (kept terms;
genes assigned to kept terms). Random control: 264 genes drawn at random from the background (the negative control of the
Results); "–": no term kept, no network.
