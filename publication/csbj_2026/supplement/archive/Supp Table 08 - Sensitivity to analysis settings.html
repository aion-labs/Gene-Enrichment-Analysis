Notes

  • Default analysis: one-sided Fisher's exact test; p < 0.01 for selection; at least 3 input genes per term; gene sets of 10–600 genes after restriction to the background (23,391 genes); at most 30 iterations per collection; the ten collections of Supplementary Table 2.
  • Random gene lists: 2,000 lists of the input size and 200 per reduced size for the q-value adjustment, generated with the setting of each row (seed 2026). With 2,000 lists the smallest attainable empirical p = (r + 1)/(n + 1) is 0.0005, shown as < 0.001. The analyses in the main text use 10,000 lists.
  • Terms kept: terms with empirical q < 0.10, which form the network. Chance terms per random list: mean number of terms selected from a random list of the same size with the same setting.
  • Same terms / genes as default: Jaccard similarity between the kept terms (or the genes assigned to them) of each setting and of the default analysis of the same gene list.
