  • Gene sets used: each gene set is first restricted to the background (23,391 validated human gene symbols) and kept if it then has 10–600 genes.
  • Genes covered: background genes in at least one used gene set; this is the collection-specific background size M of the enrichment test. *Totals of genes covered are the number of distinct genes, not the sum.
  • Input genes covered: HIV genes (265 in the background) present in the collection; this is the collection-specific input size N at the first iteration.
  • Possible terms: used gene sets that contain at least three HIV genes (the minimum overlap), i.e. the largest number of terms that could reach significance.
  • ORA: one-sided Fisher's exact test, p < 0.01, minimum overlap 3; FDR = Benjamini–Hochberg within each collection (Supplementary Table 4).
  • iGEA: terms selected by the iterative procedure (p < 0.01) and kept by the term-level filter (empirical q < 0.10, 10,000 random gene lists); kept terms form the network (Supplementary Table 5).
Gene sets: MSigDB v2025.1, human symbols harmonized to current NCBI gene symbols. Counts computed with the iGEA code (iGEA repository, publication/csbj_2026/build/supplement/collection_table_data.py and build_supp_table_02.py).
