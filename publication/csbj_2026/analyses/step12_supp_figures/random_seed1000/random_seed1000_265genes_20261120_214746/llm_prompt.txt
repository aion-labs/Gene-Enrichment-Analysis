Below is an iterative gene set enrichment (iGEA) network computed from a gene list. Iterative means that for each gene set collection, the top enriched gene set is found, saved and its genes are removed from the gene list; the remaining genes are then tested again. Thus each gene appears at most once per collection but can be linked to terms from different collections. The network of genes and gene sets (= terms) is given in DOT format, preceded by its statistics and communities.

**STATISTICAL CONTEXT:**
The input contained 263 validated genes. No term-level filter was applied (q-value threshold 1): all 11 terms selected by iGEA are in the network, which may include terms that random gene lists of this size also select by chance. Each term carries its q-value (an empirical false discovery rate estimated from 1,000 random gene lists of the same size, background and settings).

Network-level test: the largest connected cluster of this network compared with the networks built the same way (same filter) from the 1,000 random gene lists. Empirical p = (r + 1) / (1,000 + 1), where r is the number of random lists with a value at least as large. The metrics describe the same cluster and are not independent tests.

**NETWORK INTERPRETATION GUIDE (background):**
- **Term nodes** (`type=term`): enriched gene sets, with `collection` (source gene set collection), `iteration`, `p` (enrichment p-value in its iteration), `q` (term q-value) and `genes` (number of genes linked)
- **Gene nodes** (`type=gene`): input genes, with `degree` (number of terms the gene connects to; in iGEA, the number of collections that place it in the network)
- **Communities**: each `subgraph cluster_Cn` block is one community; term and gene nodes carry `community`. Bridge genes are listed outside the blocks with `bridge=true` and a `participation` value (0 = all terms in one community; higher = spread over communities).
- **Edges**: each line `"term" -- {"GENE1" "GENE2" ...}` links a term to its genes. Edges are gene-set memberships from curated annotation, not physical interactions or directions of change.

**Gene Set Collections:**
- **C2: Reactome Pathways**: Expert-curated biological pathways
- **C5: Gene Ontology: Biological Process**: Biological processes from Gene Ontology
- **C5: Gene Ontology: Cellular Component**: Cellular components from Gene Ontology
- **C5: Gene Ontology: Molecular Function**: Molecular functions from Gene Ontology

**Structure:**
1. **Executive summary**: the main findings in 4-6 plain sentences. Start with whether the network is distinguishable from random gene lists, then the overall biological picture and the most important modules and genes.
2. **Communities**: one short section per community (C1, C2, ...), headed by the community ID and a plain biological name you choose. In 3-5 sentences, explain the biology it represents in plain language, which genes anchor it and why they matter, and anything surprising. If a community looks like a mix of unrelated processes, say so; if two communities belong together, say so.
3. **Putting it together**: connected prose that combines the communities into one biological story. Give the key genes a role in that story: hubs that anchor a community, and bridge genes that link communities (what does each link suggest biologically?).
4. **Estimated experimental context**: hypothesize what experiment most likely generated this gene list (for example the type of assay, perturbation, cell type or condition). 5. **Closing**: end with one or two sentences inviting the reader to share how the gene list was actually generated (assay, perturbation, cell type, comparison), so that you can rebuild the interpretation around it: what fits the experiment, what does not, what is already known and what may be new.
